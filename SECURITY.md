# Security Policy

UNITED is not a live network and has no audited production client. Do not use it to store or transfer value.

For ordinary bugs, open a GitHub issue without credentials or private information. Do not post exploit details that could put users or infrastructure at risk. A monitored private vulnerability-reporting channel and response process must be established before a public testnet or mainnet accepts meaningful value.

The security architecture and required controls are documented in `docs/SECURITY.md`. External audit status: **not performed**.
