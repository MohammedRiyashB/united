# UNITED Mainnet Go/No-Go Checklist

**Default decision: NO-GO until every mandatory item below is evidenced and independently reviewed.**

- [ ] Public name, ticker, trademark and domain review completed.
- [ ] Legal review completed for the actual operating model and each launch jurisdiction.
- [ ] Consensus specification frozen and reviewed by independent protocol engineers.
- [ ] Mainnet genesis and all chain parameters deterministically reproducible.
- [ ] UTXO, script, subsidy, difficulty, timestamp, reorg and serialization rules implemented in production node code.
- [ ] Consensus test vectors include invalid blocks/transactions and boundary conditions.
- [ ] Fuzzing and adversarial testing completed with no unresolved critical/high findings.
- [ ] Independent external security audit published; remediation retested.
- [ ] Reproducible signed builds and documented binary verification available.
- [ ] Multiple independent seed/full-node operators and network regions available.
- [ ] Independent mining operators have tested the client and distribution is transparent.
- [ ] Wallet backup, restore, signing, fee and transaction verification independently reviewed.
- [ ] Explorer/indexer can be checked against independent full nodes.
- [ ] Monitoring, incident response, vulnerability disclosure and key-compromise plans operational.
- [ ] Public launch runbook, risk disclosures and operator instructions published.
- [ ] Public maintainer/governance decision records the GO vote and evidence links.

A website, wallet mock-up, token contract, private testnet or founder-operated node is not evidence of a safe decentralized mainnet.
